# HourGlass - A world clock application
A sleek, minimalist dashboard/app to track and convert time across global zones. Features an auto-updating grid, instant time conversion, and a clean interface that supports system dark mode. Perfect for remote teams and global travelers. Use it as a standalone web app or a desktop widget for seamless synchronization.

This tool is more than a simple clock; it is a productivity hub for digital nomads, project managers, and global developers. By removing the friction of time-zone management, it ensures you stay connected to your global network without the risk of scheduling errors.

Whether used as a pinned browser tab, a standalone desktop web app, or a mobile home-screen widget, the HourGlass offers a seamless and professional way to keep the world in sync.

# ⏳ Hourglass | Interactive World Clock

A sleek, minimalist world clock designed for managing global timezones.

### Features
* **Dynamic Backgrounds**: Transitions based on the day/night cycle of your primary pinned city.
* **"What If" Mode**: Shift time for one city and see the impact across all pinned tiles instantly.
* **Drag & Drop**: Reorder city tiles using SortableJS.
* **Master Database**: Search and pin from a curated list of global major cities.

### Tech Stack
* HTML5 / CSS3 (CSS Variables for theming)
* Vanilla JavaScript (Intl.DateTimeFormat for timezone accuracy)
* Tabler Icons & SortableJS

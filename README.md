# ⏳ Hourglass | World Clock

**A sleek, minimalist dashboard/app to track and convert time across global zones.** Features an auto-updating grid, instant time conversion, and a clean interface that supports system dark mode. Perfect for remote teams and global travelers. Use it as a standalone web app or a desktop widget for seamless synchronization.

---

### Key Features
* **Interactive "What If" Logic**: Shift time in one city and see the impact across all pinned tiles instantly.
* **Smart UI**: Dynamic background gradients that reflect day/night cycles across your selected timezones.
* **Customizable Grid**: Drag and drop tiles to prioritize your most frequent contacts.
* **Timezone Accuracy**: Powered by the native `Intl` browser API for precise offset handling.

### Tech Stack
* **Frontend**: HTML5, CSS3, Vanilla JavaScript.
* **Libraries**: [SortableJS](https://github.com/SortableJS/Sortable) for reordering, [Tabler Icons](https://tabler.io/icons).

### How to Use
1. **Pin Cities**: Use the search bar to find and add cities to your dashboard.
2. **Convert Time**: Use the "I'm wondering..." section to simulate specific times (e.g., "What time is it in my pinned cities if it's 9:00 AM in London?").
3. **Reset**: Click the **Live** button to return all clocks to the current time.
